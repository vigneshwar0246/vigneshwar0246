### ✈️ AERION / AERO-TWIN — Aircraft Engine Digital Twin

A local **research demonstrator** combining simulated engine telemetry, validated ingestion, physics-based diagnostics, an optional ML fault classifier, and a 3D dashboard.

- 🧪 A 9-class fault model openly documented as failing its `0.80` per-fault recall gate
- 🧪 A 10-class scenario classifier achieving approximately `95%` on synthetic data
- 🔁 Recorded mission replay, bounded diagnostic history, and SQLite schema v4
- ✅ CI workflow, independent audit, and `118 backend + 7 browser acceptance tests` passing at last record
- 🧾 Every score is labelled as uncalibrated and simulated—not flight-certified

**Stack:** `Python 3.13` · `FastAPI` · `scikit-learn` · `SQLite` · `React` · `Three.js` · `GitHub Actions`

[![View AERION](https://img.shields.io/badge/View%20Project-EF3B00?style=for-the-badge&logo=github&logoColor=white)](https://github.com/vigneshwar0246/Digital-twin-for-UAV-Drone)

### 🏭 AI Digital Twin — Pneumatic Cylinder Health Monitoring

Predictive maintenance for industrial automation: a live twin of a pneumatic cylinder driven by simulated sensors and machine learning.

- 📡 Simulation of pressure, temperature, position, speed, flow, vibration, load, and cycle count
- 🧠 Twenty-three engineered features for classifying `Healthy`, `Air Leakage`, `Pressure Drop`, `Seal Wear`, and `Valve Sticking`
- ❤️ Experimental health-score regressor and Remaining Useful Life estimation when a declining trend exists
- 🔌 REST and WebSocket APIs, MQTT support, and SQLite prediction history
- 🐳 Docker, Docker Compose, and Nginx deployment
- 🛡️ Advisory output only; it never operates hardware

**Stack:** `Python` · `FastAPI` · `NumPy` · `Pandas` · `scikit-learn` · `React` · `Vite` · `MQTT` · `Docker`

[![View Pneumatic Cylinder Twin](https://img.shields.io/badge/View%20Project-FF6A00?style=for-the-badge&logo=github&logoColor=white)](https://github.com/vigneshwar0246/AI-Digital-Twin-for-Pneumatic-Cylinder-Health-Monitoring)
